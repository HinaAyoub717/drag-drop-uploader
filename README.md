# Drag and Drop File Uploader

A drag and drop image uploader built for my internship task. Drop an image into the box (or click to browse), watch the progress bar, and see a preview of the image.

Live demo: https://hinaayoub717.github.io/drag-drop-uploader/

## Features
- Drag and drop or click to choose an image
- Image preview with file name and size
- Simulated progress bar (using setTimeout)
- Only JPG, PNG and GIF files are allowed
- Error message for invalid files
- Uploaded images are saved in localStorage and stay after a page refresh

## Built with
HTML, CSS and JavaScript

## What I learned
- HTML5 file input and drag and drop events (dragover, drop)
- CSS styling and animations for the drop area
- JavaScript event listeners and progress simulation
- Reading files with the FileReader API
- Saving data with localStorage

## How to run
Open `index.html` in your browser.
